# SigmaOS Roadmap

## Phase 1 (Current) — Foundation ✅

- [x] Microkernel core (scheduler, IPC, memory)
- [x] Basic filesystem (ext4, VFS, tmpfs)
- [x] Network stack (TCP/IPv4/IPv6)
- [x] Package manager (sigma-pkg)
- [x] Shell (sigma-sh)
- [x] Post-quantum cryptography
- [x] Multi-distro compatibility layer
- [x] Security input validation (SSRF-safe)

## Phase 2 (Q1 2027) — Hardware Support

- [ ] Intel GPU driver (i915)
- [ ] WiFi driver (iwlwifi, mac80211)
- [ ] Sound subsystem (ALSA-compatible)
- [ ] Bluetooth stack
- [ ] USB 4 / Thunderbolt
- [ ] NVMe multipath
- [ ] Full ACPI support

## Phase 3 (Q2 2027) — Desktop & UX

- [ ] Zenith desktop (Wayland compositor)
- [ ] Sigma App Store
- [ ] Web browser integration
- [ ] System settings UI
- [ ] Accessibility features
- [ ] Multi-language input

## Phase 4 (Q3 2027) — Advanced Features

- [ ] Kernel live patching (Ubuntu Livepatch style)
- [ ] Qubes OS-style VM compartmentalization
- [ ] NixOS-style declarative configuration
- [ ] Container runtime (OCI-compatible)
- [ ] eBPF subsystem
- [ ] ZFS filesystem support

## Phase 5 (Q4 2027) — Enterprise & Cloud

- [ ] Kubernetes node support
- [ ] Cloud-init integration
- [ ] Systemd compatibility layer
- [ ] SELinux policy toolchain
- [ ] FIPS 140-3 compliance
- [ ] Formal verification of kernel components

## Long-Term Vision

- Become a viable alternative to mainstream Linux distributions
- Complete POSIX compliance
- Hardware vendor certifications
- Independent security audits
