# Σ SIGMAOS: ARCHITECTURE SUPREMACY

## 🏛️ Repository Structure (v21.0 - Industrial Pure Silicon)

The SigmaOS repository has been architected for absolute modularity and zero-dependency purity.

### 🔱 Primary Nodes
- **`core/`**: The heart of the OS. Contains the bootloader, HAL, system primitives, and core orchestrators.
- **`suites/`**: The 33-suite Sovereign Lattice. Each suite is a self-contained functional domain.
- **`web_ui/`**: Zenith Web UI. A modular, PWA-compliant dashboard for OS interaction.
- **`meta/`**: Administrative and configuration data, sub-modularized for clarity.

### 💎 Sovereign Standards
- **Zero-Std**: Compiled with `-ffreestanding -nostdlib`. No high-level library dependencies.
- **Pure ASM**: Core primitives implemented in x86_64 assembly for direct hardware control.
- **Unified Branch**: Single source of truth on the `main` branch.

### 🛠️ Orchestration
- `Makefile`: Universal build system (Modernized).
- `build_sovereign.ps1`: PowerShell-native build orchestrator.
- `run_sigma_tests.ps1`: Atomic shard verification suite.
