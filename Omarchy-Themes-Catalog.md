## 🚀 Instant Theme Switching in SigmaOS
Switch themes instantly with zero flickering using the native CLI:
```bash
sigmaos-theme set catppuccin
sigmaos-theme set tokyo-night
sigmaos-theme set gruvbox
```

Or graphically using the Zenith Desktop Quick Settings panel (`Super + Space` -> Themes).
