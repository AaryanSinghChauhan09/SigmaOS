# Upstream Study: xv6 / OSDev Minimal Kernel Architecture

## Overview
This directory contains study notes, control flow analyses, and data structure descriptions for xv6 and early OSDev kernel mechanics.

## Key Focus Areas
- Minimal bootloaders (x86_64 UEFI / BIOS)
- GDT, IDT, and hardware interrupts
- xv6 process model and context switching
- Minimal VFS and inode-based filesystem structures
