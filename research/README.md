# SigmaOS Research Repository

This directory contains research notes, architecture decision records (ADRs), domain comparison matrices, and study reports for SigmaOS.

## Subdirectories

- `upstream/`: Notes and maps from upstream OS reference studies (xv6, Linux, Redox, Arch, Mint, FreeBSD, OpenBSD, Debian, Fedora, NixOS, OSDev).
- `decisions/`: Architecture Decision Records (ADR-001 through ADR-005+).
- `comparisons/`: Mechanism comparison matrices across operating systems.
- `reports/`: Periodic study reports (daily, weekly, monthly, quarterly).
