# Drivers Branch Wiki (SDF)

This knowledge base governs the Sovereign Driver Framework (SDF) within the `drivers` branch.

## Focus Areas

- **Hardware Abstraction Layer (HAL)**: Interfacing the driver logic with raw PCIe/USB hardware buses.
- **Driver Development Guides**: How to write isolated, user-space drivers for SigmaOS.
- **Regression Testing**: Automated tooling (`SovereignFuzzer`) to ensure new hardware modules don't trigger kernel panics.
