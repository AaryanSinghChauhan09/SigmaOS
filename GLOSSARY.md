# Σ SIGMAOS: SOVEREIGN GLOSSARY

This document defines the unique terminology used in the SigmaOS Zenith Supreme architecture to assist contributors and security auditors.

| Term | Definition |
| :--- | :--- |
| **Sovereign Shard** | An atomic, modular unit of code (C11/ASM) that performs a specific OS function with zero external dependencies. |
| **Zenith Phase** | A project roadmap milestone representing a peak in architectural stability and functional parity. |
| **Amalgamation Matrix**| The system-wide registry of features absorbed from major OS distros (Linux, BSD, Windows). |
| **Purity Audit** | The automated verification process ensuring zero unauthorized high-level language dependencies (e.g., `<stdio.h>`). |
| **Vantage Interface** | The web-based dashboard for real-time visual auditing of the kernel's sharded state. |
| **Bit-Perfect INIT** | The deterministic, dependency-aware initialization sequence of the Sovereign Orchestrator. |
| **Shard Coupler** | The registry-based interface used to bind shards with minimal architectural coupling. |
| **Sovereign LibC** | The custom, zero-wait C library primitives native to SigmaOS. |
