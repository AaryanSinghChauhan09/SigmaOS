# SigmaOS Changelog

All notable changes to the SigmaOS project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Sovereign Versioning](https://github.com/AaryanSinghChauhan09/SigmaOS).

## [150.0] - 2026-03-30

### Added

-   **Autonomous Sentinel System**: Self-healing silicon that intercepts CPU traps and resolves errors using automated silicon-rollback.
-   **Zero-CRT0 Entry Point**: Bypassed standard compiler entry points using `SovereignEntry.asm` for absolute kernel control.
-   **Silicon-Scrubbing Security**: ASM-level register and stack scrubbing for zero-leak privacy of personal information.
-   **Local Distro Parity**: New `scripts/SigmaDistroRunner.ps1` to execute any Linux distribution (Ubuntu, Arch, etc.) locally on the SigmaOS Aether-WSW shard.
-   **Ubuntu-Elite UI/UX**: Elevated **Yaru-Gold** design system for a premium, industrial-grade interface experience.
-   **USP Absorption**: Integrated features and USPs from major Linux distributions (Ubuntu, Debian, Arch, etc.) and automation tools (AutoKey, Merlin-IA, etc.).
-   **Missing Repository Documentation**: Added `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md`, and `AUTOMATION_ZENITH.md`.

### Fixed

-   **Repository Sync Integrity**: Resolved all errors in the GitHub repository and ensured bit-perfect synchronization.
-   **Makefile Linking**: Fixed entry point conflicts and integrated all new v150.0 shards into the industrial build chain.
-   **Compiler Runtime Dependency**: Purged all remaining high-level language runtimes and predefined headers.

### Changed

-   **Aether-Orchestrator**: Upgraded to v2.0 for multi-model AI orchestration (Claude, Gemini, GPT-4).
-   **Omni-Shell**: Refactored to pure C11 for zero-dependency finality.
