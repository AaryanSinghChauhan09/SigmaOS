# Changelog

All notable changes to the SigmaOS project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- **Sovereign Object-Oriented Foundation (SOOF)**: Unified object system across all subsystems.
- **Multiverse Dual Boot Host**: Integrated UI to seamlessly partition and boot Windows 11, macOS, and Linux sub-environments within the Zenith Dashboard.
- **Micro-Shard Ecosystem Delivery**: Decomposed apps into fine-grained functional shards limiting memory/storage consumption.
- **Contributor Scaffolding**: Added CODE_OF_CONDUCT, CONTRIBUTING, and issue templates.
- **Fluent UI Upgrade**: Zenith Dashboard fully remodeled utilizing Windows 11 / macOS glassmorphic aesthetic.

### Changed
- Refactored Memory, Network, Orchestrator, and Intelligence shards to inherit from `sigma_obj_t`.

### Removed
- Legacy matrix glitch artifacts from Zenith UI.
- Recursive nested dependencies in the core compiler toolchain.

## [1.0.0-rc.1] - 2026-04-15
### Added
- Initial 33-suite Lattice core.
- Neural balancer scheduler.
- Post-Quantum Cryptography implementations (Kyber/Dilithium).
