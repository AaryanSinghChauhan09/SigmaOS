
```bash

```
Engages **S55 (Lattice Block)** to filter network traffic at the kernel level. It eradicates ads, trackers, and popups across the entire OS, providing a cleaner and faster experience than any browser extension.

### Native PDF Engine
```bash
./s-cli pdf [read|edit|convert]
```
Provides a high-performance, bare-metal PDF engine (**S53**) for viewing and manipulating documents without external software.

### Media & YouTube Enhancement
```bash
./s-cli enhance
```
Activates **S56 (Zenith Enhancer)** to super-charge the media experience. It provides granular control over video speed, pitch, and layout, and integrates automatic skip-tools for non-essential content.
