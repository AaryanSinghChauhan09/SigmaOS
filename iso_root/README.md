# SigmaOS Installation Media

Welcome to SigmaOS v29.0 Zenith Foundation - A sovereign, AI-native operating system designed for the modern era.

## Boot Options

- **SigmaOS v29.0 Zenith Foundation (Boot)** - Standard boot mode
- **SigmaOS v29.0 Zenith Foundation (Safe Mode)** - Single user mode for troubleshooting
- **SigmaOS v29.0 Zenith Foundation (Verbose)** - Boot with verbose logging
- **SigmaOS v29.0 Zenith Foundation (Debug)** - Boot with debug enabled

## System Information

- **Architecture**: x86_64
- **Kernel**: Sovereign Microkernel
- **Boot Mode**: Multiboot2 / EFI
- **Version**: 29.0 Zenith Foundation

## Installation

To install SigmaOS, run the installer from the boot menu or execute:

```bash
sudo /installer/install.sh
```
