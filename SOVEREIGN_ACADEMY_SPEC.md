# 📟 SigmaOS: Sovereign Orchestrator v3.6 (Academy Ready)

The **Sovereign Orchestrator v3.6** transforms SigmaOS into the ultimate academic workstation by natively integrating the NCERT syllabus and simulation engines.

## 🎓 Sovereign Academy Commands

### NCERT Syllabus Mode
```bash
./s-cli academy [class] [subject]
```
Initializes the **Sovereign Academy** environment. It locks the UI into a focus-mode state, drops non-educational network packets, and maps the specified NCERT syllabus directly into the lattice framebuffer.

### Experiment Simulator
```bash
./s-cli sim [experiment_name]
```
Utilizes **S50 (NCERT Simulator)** to run high-fidelity mathematical and physical simulations on bare metal. It eliminates browser-based lag by rendering simulations directly via the UAL.

### Native Mathematical Solver
```bash
./s-cli solve [equation]
```
Dispatches mathematical queries to **S51 (NCERT Calculators)**. It utilizes **S44 (Sovereign ASM)** for vectorized floating-point acceleration, achieving instantaneous solutions for complex academic problems.
