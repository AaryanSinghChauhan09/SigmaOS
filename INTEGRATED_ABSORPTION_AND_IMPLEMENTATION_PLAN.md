## 🎯 Phased Agent Checklists

During each phase of system realization, the agents must execute their specialized checklists:

### ⚡ Phase A - Base Stabilization
- **Bolt:** Profile boot latencies; hoist MMIO register lookups out of early boot loops; ensure O(1) Slab allocator contains no lock-inversion blocks.
- **Palette:** Integrate early graphical GOP boot splasher with dynamic responsive progress scaling.
- **Sentinel:** Validate capability token checks on early boot threads; compile under strict `#![deny(unsafe_code)]` wherever possible.

### 🚗 Phase B - Peripheral Parity & Drivers
- **Bolt:** Implement zero-copy physical page-walking for block device transfers (DMA); pre-allocate audio buffers to eliminate real-time allocation gaps.
- **Palette:** Implement screen reader notifications for driver initialization successes and connect/disconnect events.
- **Sentinel:** Hardcode strict I/O bounds for custom driver parameters to prevent buffer overruns; isolate each driver into its own user-space address ring.

### 📦 Phase C - Subsystem Expansion & Runtimes
- **Bolt:** Replace traditional heap cloning with lazy, allocation-free reference iteration within the universal package manager's SAT solver.
- **Palette:** Ensure CLI tools (multi-call binary and custom shell) support proper help structures, screen-reader descriptions, and color-contrast modes.
- **Sentinel:** Sandbox container namespaces with strict isolation boundaries; enforce digital signature and hash checks over all downloaded package files.

### 🎨 Phase D - Desktop & Unified UX
- **Bolt:** Optimize compositing paint loops via direct Vulkan surface walking, skipping high-frequency pixel translations.
- **Palette:** Ensure absolute compliance with keyboard tab index maps, active focus indicators, and custom smooth UI springs.
- **Sentinel:** Harden desktop IPC handlers against overflow probes; enforce strict window isolation so applications cannot spy on neighboring frames.

### 🌌 Phase E - Sovereign Scale
- **Bolt:** Optimize local transformer AI weight mapping with zero-copy file-backed `mmap` allocation layouts.
- **Palette:** Design high-fidelity visual telemetry dashboards mapping system metrics.
- **Sentinel:** Enforce post-quantum encryption across all network transfers; deploy real-time signature scanners monitoring filesystem changes.

## 🔄 The Continuous Integration & Sync Pipeline

1. **Check:** Every change passes through standard compilation tests (`cargo check`/`cargo test`).
2. **Review:** The three agent teams check pull requests to ensure they adhere to optimization, accessibility, and security guidelines.
3. **Log:** Keep learnings updated within `.jules/` journals to maintain a growing knowledgebase of system patterns and prevent regressions.
