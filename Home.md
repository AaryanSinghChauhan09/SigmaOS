## What is SigmaOS?

SigmaOS is a from-scratch operating system that combines:

- **Rust safety** — memory-safe kernel with no-std/no-libc core
- **Microkernel architecture** — minimal trusted computing base
- **Post-quantum cryptography** — Dilithium-5 and Kyber-1024 built-in
- **Multi-distro parity** — native compatibility with Arch, Debian, Fedora, and more
- **AI integration** — S-AI engine for intelligent system management
- **Zenith desktop** — modern GTK-style desktop environment
