## Additional information

### Package search

Search for packages:

```bash
sigpkg search keyword
```

### Package information

Get package details:

```bash
sigpkg info package-name
```

### Multi-distro support

SigmaOS supports packages from multiple distributions:
- Arch Linux (PKGBUILD, AUR)
- Debian/Ubuntu (DEB)
- Fedora/RHEL (RPM)
- And more through adapters
