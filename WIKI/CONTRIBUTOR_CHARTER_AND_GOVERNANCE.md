# SigmaOS Contributor Charter & Community Governance Model

Welcome to the **SigmaOS Community & Open Source Governance Charter**! This document outlines our governance structure, contributor rights, code submission guidelines, and community roadmap.

---

## 🏛️ Governance Principles

1. **Open Sovereign Computing**
   SigmaOS is committed to complete hardware sovereignty, zero-telemetry user privacy, and firmware-free transparent driver architecture.
2. **Meritocratic Technical Review**
   All pull requests are evaluated objectively using automated quality gates (`./scripts/sigma_quality_check.sh`), security audits, and peer code review.
3. **Inclusive & Welcoming Community**
   We enforce a strict Code of Conduct upholding respectful collaboration across developers, security researchers, and enthusiasts.

---

## 🤝 Contribution Guidelines & Hackathons

### How to Contribute
- **Bug Fixes & Driver Extensions**: Submit pull requests following our conventional commit format.
- **Hackathons & Sprints**: We host quarterly open-source hackathons focusing on:
  - Rust-native firmware-free device drivers.
  - Zenith Compositor UI applets and Shards Marketplace apps.
  - Multi-ISA CPU kernel optimization (x86, ARM64, RISC-V, LoongArch).
