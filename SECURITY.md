# SigmaOS Security Management Plan

This repository strictly adheres to the SigmaOS Security Management Plan aligned with NIST SP 800-218 (Secure Software Development Framework - SSDF) and mature Linux/BSD distribution security practices.

For the complete, authoritative Security Management Plan, including baseline security rules, 16-PR proposed security roadmap, periodic security review cadence, component-specific security rules, and PR merge gates, see:

- [SigmaOS Security Management Plan (`docs/SECURITY.md`)](docs/SECURITY.md)
- [GitHub Security Policy (`.github/SECURITY.md`)](.github/SECURITY.md)

## Vulnerability Reporting

- **Private Reporting Only:** Do NOT post unpatched security vulnerabilities or exploit details in public issues or PRs.
- **Reporting Channels:**
  - GitHub Private Vulnerability Reporting tab in this repository.
  - Direct email: `security@sigmaos.org`
- **Initial Acknowledgement SLA:** Within 3 business days.
