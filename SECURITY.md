# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v100.0  | :white_check_mark: |
| < v100.0| :x:                |

## Reporting a Vulnerability

Open a [GitHub Issue](https://github.com/AaryanSinghChauhan09/SigmaOS/issues) or email the maintainer directly. Since SigmaOS is a browser-based simulation, most security concerns will be related to the static HTML/JS.
