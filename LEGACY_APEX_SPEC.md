## 🚀 Legacy Apex Commands

### SigmaShell (S65)
```bash
./s-cli shell
```
Transitions the session into **SigmaShell**, the native sovereign CLI environment. It provides a direct, zero-overhead interface to the kernel lattice, allowing for real-time shard orchestration and system debugging.

### Industrial Benchmarking
```bash
./s-cli bench
```
Performs an industrial-grade performance audit. It measures boot times, IPC latencies, and memory footprints, demonstrating SigmaOS's technical superiority over legacy Linux distributions.

### Tensor Direct Pipeline (S69)
```bash
./s-cli tensor
```
Initializes the **Tensor Direct** pipeline for zero-copy AI acceleration. It maps system memory directly to hardware NPUs/GPUs, eliminating the middleware bloat typically found in legacy AI runtimes.
