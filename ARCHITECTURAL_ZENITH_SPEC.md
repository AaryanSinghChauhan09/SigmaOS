```bash
./s-cli evolve
```

```bash
./s-cli isolate [shard_id]
```
Utilizes **S49 (Sovereign Enclave)** to deploy high-sensitivity shards into hardware-enforced isolation zones (Intel SGX / ARM TrustZone). This ensures that even a compromised kernel lattice cannot access enclave memory.

### Post-Quantum Security
```bash
./s-cli quantum
```
Upgrades the lattice mesh communication to utilize **Post-Quantum Cryptographic** primitives (Kyber/Dilithium). This ensures that all inter-shard and inter-node handshakes are resilient against future quantum-decryption attacks.
