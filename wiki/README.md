## Getting Started

### Installation

For installation instructions, see the main [README.md](../README.md) in the repository root.

### Quick Start Guide

1. Clone the repository
2. Build the kernel: `cargo build --release`
3. Run in QEMU: `./scripts/qemu_smoke_test.py`
