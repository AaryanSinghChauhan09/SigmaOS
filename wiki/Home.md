## About SigmaOS

SigmaOS is built on these principles:
- 🔒 **Sovereignty**: Full hardware control, no telemetry, no backdoors
- ⚡ **Performance**: CachyOS-inspired EEVDF scheduler + eBPF-native kernel
- 🤖 **AI-Native**: Built-in S-AI multi-agent orchestrator (100% local)
- 🛡️ **Security**: SELinux + AppArmor + Sentinel + eBPF firewall
- 🌐 **Compatibility**: AUR + Flatpak + AppImage + .deb + Nix
- 🧬 **Open**: Fully open source, community governed
