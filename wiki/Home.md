## System Overview
SigmaOS is a fully sovereign, zero-dependency, self-sufficient operating system written in Safe Rust. It eliminates the need for any external software downloads by natively integrating media players, office suites, graphics editors, AI/LLM models, ML runtimes, database engines, robotics simulators, and security tools directly into its Core System Shards and `klib` standard library.
