# Welcome to the SigmaOS Wiki

**SigmaOS** is a sovereign, zero-dependency, ultra-high-performance, security-hardened, and universally compatible operating system written in safe Rust.

- **Target Repository:** [https://github.com/AaryanSinghChauhan09/SigmaOS](https://github.com/AaryanSinghChauhan09/SigmaOS)

## Tri-Agent Governance Framework & 500+ Open-Source Repositories Absorption

SigmaOS utilizes a three-agent continuous development model and absorbs innovations from over 500 open-source GitHub repositories:

1. **Bolt ⚡ (Performance Specialist):** Focuses on sub-millisecond execution, lock-free data structures, zero-copy memory pipelines, and low memory footprints. Journal: `.jules/bolt.md`.
2. **Palette 🎨 (UX & Accessibility Specialist):** Ensures WCAG 2.1 AAA compliance, full keyboard tab navigation, visible focus indicators, and semantic ARIA labeling for Zenith Desktop and Web UI. Journal: `.jules/palette.md`.
3. **Sentinel 🛡️ (Security Specialist):** Enforces defense-in-depth, memory zeroization, strict capability bounds (`pledge`/`unveil`/`landlock`), and vulnerability remediation. Journal: `.jules/sentinel.md`.

For the complete specification and repository mapping, see `docs/SIGMAOS_MASTER_PLAN_TRI_AGENT_500_REPOS_ABSORPTION.md`.
