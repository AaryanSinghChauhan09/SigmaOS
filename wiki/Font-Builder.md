# Font Builder

SigmaOS's **Sigma Font Builder** is a Nim-powered font compilation engine — inspired by the Omarchy `dev-font-builder` branch — that generates `@font-face` CSS, fontconfig XML, and automated build scripts for TTF/OTF/WOFF2 font families.

---

## Architecture Comparison

| Metric | Omarchy dev-font-builder | Linux Mint (n/a) | SigmaOS Font Builder |
|---|---|---|---|
| Core language | Shell / Python | — | **Nim** (zero-dep, native binary) |
| CSS generation | Manual | — | Auto-generated `@font-face` blocks |
| fontconfig XML | Manual | — | Auto-generated `fonts.conf` fragment |
| Weight support | Basic | — | All 9 CSS weight classes (100–900) |
| WOFF2 | No | — | Auto-compressed via fonttools |
| Variable font support | No | — | Yes (marked as variable family) |
| Unicode ranges | None | — | Per-variant unicode-range spec |
| Build script gen | None | — | Bash build script with fc-cache |

---

## Architectural Highlights

- **Zero external Nim dependencies** — uses only `std/[strutils, sequtils, os, strformat, algorithm]`
- **9 font weight classes** — `Thin(100)` through `Black(900)` as typed enums
- **3 font styles** — `Normal`, `Italic`, `Oblique`
- **4 font formats** — `TTF`, `OTF`, `WOFF2`, `Variable`
- **@font-face CSS generator** — emits complete CSS with `font-display: swap`, unicode-range, and WOFF2 src
- **fontconfig XML** — writes `<dir>` and `<alias>` blocks for system-wide font registration
- **Bash build script** — installs fonts, optionally runs `fonttools` WOFF2 compression, and calls `fc-cache`
- **Sorted weight output** — CSS blocks always emitted in ascending weight order

## API & Usage (Nim)

```nim
import font_builder

var builder = newSigmaFontBuilder("/usr/share/sigmaos/fonts")

# Register JetBrains Mono
let jbm = builder.registerFamily("JetBrainsMono", "JetBrains Mono", variable = true)
builder.addVariant(jbm, "JetBrainsMono-Regular.ttf", wRegular)
builder.addVariant(jbm, "JetBrainsMono-Bold.ttf", wBold)
builder.addVariant(jbm, "JetBrainsMono-Italic.ttf", wRegular, fsItalic)

# Register Inter UI
let inter = builder.registerFamily("Inter", "Inter", variable = true)
builder.addVariant(inter, "Inter-Regular.ttf", wRegular)
builder.addVariant(inter, "Inter-SemiBold.ttf", wSemiBold)
builder.addVariant(inter, "Inter-Bold.ttf", wBold)

# Generate outputs
writeFile("/etc/fonts/conf.d/99-sigmaos.conf", builder.generateFontconfigXml())
writeFile("/usr/share/sigmaos/fonts/fonts.css", builder.generateFontCSS())
writeFile("/tmp/build-fonts.sh", builder.generateBuildScript())

echo "Total variants: ", builder.totalVariantCount()
```

## Generated CSS Sample

```css
/* SigmaOS Font Bundle — auto-generated by sigma-font-builder */

/* === JetBrains Mono === */
@font-face {
  font-family: 'JetBrains Mono';
  font-weight: 400;
  font-style: normal;
  font-display: swap;
  src: url('/usr/share/sigmaos/fonts/JetBrainsMono-Regular.woff2') format('woff2');
  unicode-range: U+0000-00FF, U+0131, ...;
}
```

## SigmaOS Default Font Stack

|---|---|---|
| Code / Terminal | JetBrains Mono | Variable TTF + WOFF2 |
| UI / System | Inter | Variable TTF + WOFF2 |
| Document | Noto Serif | TTF |
| Icon | Nerd Fonts Symbols | OTF |
