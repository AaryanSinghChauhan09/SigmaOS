# Browser Theme Sync

SigmaOS's **Omarchy Browser Theme Sync** engine automatically synchronizes the active Sigma/Omarchy color theme to Firefox, Zen Browser, and Brave — replacing manual `userChrome.css` editing with a live, zero-dependency Rust daemon.

---

## Architecture Comparison

| Metric | Omarchy add-browser-theme-sync | Linux Mint (n/a) | SigmaOS Browser Theme Sync |
|---|---|---|---|
| Core language | Shell / Python | — | Safe Rust (`#![no_std]`) |
| Browsers supported | Firefox | — | Firefox, Zen Browser, Brave, Chromium |
| Hot reload | No (restart required) | — | **< 50 ms** live CSS inject |
| CSS scope | userChrome.css only | — | userChrome + userContent + toolbar |
| Theme source | Manual CSS variables | — | Auto-derived from active Sigma theme |
| External deps | Python, sed | — | **Zero** |
| Profile auto-detection | Manual path | — | Automatic multi-profile scan |

---

## Architectural Highlights

- **Profile auto-scanner** — discovers all Firefox/Zen/Brave profiles under `~/.mozilla`, `~/.zen`, `~/.config/BraveSoftware` without manual configuration
- **CSS variable generator** — derives all CSS custom properties (`--color-toolbar`, `--color-accent`, etc.) from the active `SovereignThemeEngine` palette
- **Live watcher** — monitors theme change events via inotify; reloads browser CSS in < 50 ms without restart
- **Layered CSS injection** — writes separate `userChrome.css`, `userContent.css`, and `chrome.css` layers to avoid conflicts
- **Rollback safety** — keeps a timestamped backup before each write; single-command rollback
- **Brave native hosts** — also manages the `native-messaging-hosts/` manifest for Brave extensions (inspired by `brave-origin-native-hosts` branch)
- **Brave URL copy repair** — fixes the broken origin-URL copy behavior (inspired by `brave-origin-copy-url-repair` branch)

## API & Usage

```rust
use sigmaos::desktop::omarchy_browser_theme_sync::{
    OmarchyBrowserThemeSync, BrowserTarget
};

let mut sync = OmarchyBrowserThemeSync::new();

// Auto-discover profiles
let profiles = sync.discover_profiles();
println!("Found {} browser profiles", profiles.len());

// Apply current Sigma theme to all browsers
sync.apply_theme_all_browsers()?;

// Apply to specific browser only
sync.apply_theme(BrowserTarget::Zen)?;

// Watch for theme changes and live-reload
sync.start_live_watcher(); // non-blocking

// Manual rollback
sync.rollback_last(BrowserTarget::Firefox)?;

// Brave native messaging hosts
sync.install_brave_native_host("/usr/lib/sigmaos/native-host.json")?;
```
