# Help:Browsing

This page explains how to effectively browse and search the SigmaOS Wiki.

## Navigation

### Sidebar Navigation
The sidebar provides quick access to major wiki sections:
- **Navigation**: Help pages and wiki contribution guides
- **The Distribution**: Core distribution information
- **Desktop Environment**: Zenith compositor and workflow
- **Package Management**: SigmaPkg and package systems
- **System Administration**: System management and services
- **Security & Hardening**: Security features and hardening
- **Performance & Kernel**: Performance tuning and kernel features
- **Maintenance & Recovery**: System maintenance and recovery
- **Hardware & Platform**: Hardware support and platforms
- **Community**: Community guidelines and participation
- **Reference**: Reference documentation and analyses

### Internal Links
Internal wiki links are shown as regular links and navigate to other wiki pages. Click on any link to visit the related page.

### External Links
External links (to GitHub, other sites) are also shown as regular links but lead to external resources.

## Searching

### Using GitHub Search
The SigmaOS Wiki is hosted on GitHub, so you can use GitHub's search functionality:

1. Go to the [SigmaOS repository](https://github.com/AaryanSinghChauhan09/SigmaOS)
2. Use the search bar at the top
3. Select "Wikis" from the search scope dropdown
4. Enter your search terms

### Search Tips
- **Use Specific Terms**: Use specific technical terms rather than general concepts
- **Search in Code**: If looking for implementation details, search in the code repository
- **Check Issues**: Related discussions might be in GitHub Issues
- **Use Filters**: Use GitHub's search filters to narrow results

## Viewing the Wiki Offline

### Using GitHub
You can view the wiki offline by:

1. **Clone the Wiki Repository**:
   ```bash
   git clone https://github.com/AaryanSinghChauhan09/SigmaOS.wiki.git
   cd SigmaOS.wiki
   ```

2. **View Files**: Open `.md` files in any markdown viewer or text editor

### Using Git
You can also clone the main repository which contains wiki mirrors:

```bash
git clone https://github.com/AaryanSinghChauhan09/SigmaOS.git
cd SigmaOS/wiki_repo
```

## Mobile Access

The GitHub Wiki is mobile-friendly and can be accessed from any device with a web browser. For the best experience:

- Use a modern web browser
- Enable JavaScript for full functionality
- Consider using the GitHub mobile app

## Keyboard Shortcuts

GitHub provides keyboard shortcuts for navigation:

- `s` - Focus search bar
- `/` - Search in current repository
- `?` - Show keyboard shortcuts
- `t` - File finder
- `w` - Switch to wiki
- `g` then `i` - Go to issues
- `g` then `p` - Go to pull requests
