# SigmaOS Theming System Components

## Overview
SigmaOS theming system providing base 8 to 24 colors, competitive with Omarchy's theming system (base 8 to 24 colors, autogenerated themes from wallpaper).

## Features
- **Base 8 colors** (terminal standard)
- **Extended 16 colors** (brighter variants)
- **Full 24 colors** (Omarchy's expansion)
- **Auto-generate themes from wallpaper** (like Omarchy)
- **Default themes**: catppuccin-mocha, catppuccin-latte
- **Customizable**: font, bar position, bar transparency
- **24-color palette** like Omarchy's expansion

## Structures

| Structure | Description |
|-----------|-------------|
| **ThemeManager** | Theme manager with theme registry |
| **Theme** | Theme definition with palette |
| **ColorPalette** | Base 8, Extended 16, Full 24 colors |
| **ThemeColor** | Individual color (name, hex, RGB, HSL) |
| **BarPosition** | Top, Bottom, Left, Right |

## Usage Examples

```rust
// Create theme manager
let mut manager = ThemeManager::new("/etc/sigmaos/themes".to_string());

// Register default themes
manager.create_default_themes();

// Set active theme
manager.set_active_theme("catppuccin-latte").unwrap();

// Generate theme from wallpaper (Omarchy feature)
manager.generate_from_wallpaper("/usr/share/wallpapers/nature.jpg").unwrap();

// Get active theme
let theme = manager.get_active_theme().unwrap();
```
