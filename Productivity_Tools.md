# Productivity Tools Bundle

SigmaOS pre-bundles a complete productivity ecosystem to ensure immediate usability upon first boot, managed via `sigpkg`.

## Bundled Office & Media Suite
- **Office:** LibreOffice (Writer, Calc, Impress) integrated with the Zenith UI.
- **Web Browser:** A hardened Chromium or Firefox build with uBlock Origin pre-installed and telemetry stripped.
- **Email/Calendar:** Thunderbird / Evolution, sandboxed into a MicroVM.
- **File Management:** A native Wayland file explorer with built-in compression/extraction utilities.
- **Media & PDF:** VLC for video/audio, Okular/Evince for PDF reading and editing.
