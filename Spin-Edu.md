# SigmaOS Edu Spin — Student & Educator Edition

The **SigmaOS Edu** spin is SigmaOS's answer to Debian Edu/Skolelinux — a learning-first environment designed for students, teachers, and institutions. It ships a complete sovereign classroom toolkit with offline-capable tools.

---

## 📚 Office & Productivity Suite

| Tool | Purpose |
|------|---------|
| LibreOffice | Writer, Calc, Impress, Draw |
| Okular | PDF reader & annotation |
| Zotero | Research citation manager |
| Obsidian | Sovereign note-taking (Markdown-based) |

## 🎓 E-Learning & Education Tools

- **Moodle Desktop Client** — connect to LMS platforms
- **Anki** — spaced-repetition flashcard system
- **GCompris** — educational games for K-12
- **Marble** — interactive geography & maps
- **KStars** — astronomy simulation & planetarium

## 💻 Programming Education

| Tool | Level |
|------|-------|
| Scratch 3 | Beginner visual programming |
| Thonny IDE | Python for beginners |
| Mu Editor | MicroPython / Circuit Python |
| Jupyter Notebook | Interactive computing |
| Code::Blocks | C/C++ intro for CS students |

## 🤝 Collaboration & Communication

- **Nextcloud** — sovereign file sync & collaborative editing (self-hosted)
- **Etherpad** — real-time collaborative text editing
- **Element (Matrix)** — sovereign encrypted classroom chat
- **Jitsi Meet** — self-hosted video conferencing

## 🎨 Creative Learning

- **Krita** — digital art for art classes
- **Audacity** — audio editing for music courses
- **Kdenlive** — video editing for media studies

## 🔒 Privacy & Safety

- **Parental controls** via sovereign profile manager
- **AppArmor** profiles pre-configured for student sandboxing
- **DNS-over-HTTPS** with content filtering (educational mode)

## 🌐 Offline-First Design

SigmaOS Edu is designed to work **without internet access** — all core tools work fully offline. Sync happens automatically when connectivity is restored via Nextcloud.

---

## 🚀 Installation

```bash
sigma-spin install edu
```
