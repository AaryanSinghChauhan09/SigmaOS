# 🎨 Palette's Journal - UX & Accessibility Critical Learnings

## 2025-02-23 - Interactive Terminal CLI & Zenith Desktop A11y
**Learning:** Terminal user interface (TUI) and Zenith Desktop web components in `web_ui/` and package CLI tools require accessible ARIA tags, visible focus rings, and clear interactive status indicators during transactional package installations and system state rollbacks.
**Action:** Ensure all interactive CLI routers and desktop UI widgets provide aria-live regions, clear progress indicators, and keyboard-accessible focus management.
