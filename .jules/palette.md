## 2026-10-22 - Keyboard Focus and Accessibility Traps in Zenith Desktop Window Switching
**Learning:** Icon-only desktop bar widgets lacked accessible ARIA labels and focus indicators, causing screen reader users and keyboard-only operators to miss workspace status updates.
**Action:** Always pair `aria-label` attributes with visible focus rings and explicit state feedback across desktop UI components.
