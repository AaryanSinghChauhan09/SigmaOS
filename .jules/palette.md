## Critical Learnings & A11y Standards

### 2026-03-30 - High Contrast Terminal & Desktop Indicators
**Learning:** Terminal userland apps and desktop shell interfaces require high-contrast ARIA focus state indicators (`focus-visible:ring-2`) and clear visual feedback for interactive widgets.
**Action:** Ensure all interactive elements include semantic accessibility hints, keyboard shortcut indicators, and explicit high contrast focus indicators.
