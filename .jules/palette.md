# 🎨 Palette's Journal - Critical UX & Accessibility Learnings

## 2025-05-20 - Accessible CLI Feedback & Visual Progress Indicators
**Learning:** Terminal-based setup wizards and package managers in sovereign OS environments often lack proper keyboard navigation, ARIA-equivalent stdout announcements, and accessible status indicators during async installation phases.
**Action:** Always provide inline progress spinners, keyboard shortcut hints, and explicit status states in Zenith Desktop and CLI wizard components.

## 2025-05-21 - Unified Light/Dark High-Contrast Theme System
**Learning:** Desktop shell components require standard contrast ratios (4.5:1 for normal text, 3:1 for large text) across high-DPI displays.
**Action:** Ensure default color tokens in Zenith Desktop CSS enforce WCAG 2.1 AA accessibility guidelines.
