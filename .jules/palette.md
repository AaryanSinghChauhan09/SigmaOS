## 2026-10-07 - Accessible Status Indicators & Desktop Telemetry Feedback
**Learning:** Terminal and web desktop interfaces like Zenith Desktop and web UI require clear visual status feedback for asynchronous operations, status badges with accessible ARIA labels, and explicit focus rings for keyboard navigation.
**Action:** Always provide visual status indicators, high-contrast focus visible rings (`focus-visible:ring-2`), and semantic ARIA states (`aria-live="polite"`, `aria-expanded`, `aria-label`) across UI components.
