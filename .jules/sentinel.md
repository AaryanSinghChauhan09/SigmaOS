## 2026-09-14 - POSIX Environment Variable Key Format Injection Security Vulnerability
**Vulnerability:** `validate_env_key` permitted environment variable key names starting with digits or containing hyphens, equals signs, NUL bytes, or special shell characters (`FOO$BAR`, `123VAR`, `MY-VAR`), which can lead to environment injection, process environment corruption, and security filter bypasses.
**Learning:** Checking only for `=` and `NUL` bytes is insufficient for environment key validation because POSIX IEEE Std 1003.1 dictates strict identifier rules (`[a-zA-Z_][a-zA-Z0-9_]*`). Permitting special characters or leading digits allows attackers to inject or override process environment variables across subshells or native executables.
**Prevention:** In environment variable validation routines, enforce POSIX variable naming standards by verifying that the initial byte is `[a-zA-Z_]` and subsequent bytes are `[a-zA-Z0-9_]`. Reject any keys containing hyphens, digits at the start, shell characters, or non-alphanumeric symbols.
