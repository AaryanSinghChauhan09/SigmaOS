# Governance & Contribution Guidelines

Rules, policies, and processes that govern SigmaOS development and contribution.

## Governance Files

- **COMPONENT_RULES.toml**: Component definition and registration rules
- **PROCESS_RULES.toml**: Development process and workflow requirements
- **MEMORY_RULES.toml**: Memory management and safety policies
- **SCHEDULER_RULES.toml**: Scheduling decisions and constraints
- **IO_RULES.toml**: I/O operations and device management policies
- **VFS_RULES.toml**: Filesystem operations and semantics
- **STORAGE_RULES.toml**: Data storage and persistence requirements
- **SHELL_RULES.toml**: Shell and command-line interface standards

## Contribution Guidelines

- Code style and formatting standards
- Testing requirements and coverage expectations
- Documentation standards
- Code review process and expectations
- Commit message conventions
- Release process and versioning

See individual RULES files for specific domain policies.
