# Assets Directory

Static assets, images, diagrams, and other media used throughout the SigmaOS documentation.

## Organization

- **images/**: PNG, JPG, and SVG images
- **diagrams/**: Architecture and system diagrams
- **screenshots/**: UI screenshots and demonstrations

## Asset Guidelines

- Use descriptive filenames (e.g., `scheduler-architecture-overview.svg`)
- Include alt text for all images in documentation
- Keep file sizes reasonable for web delivery
- Prefer vector formats (SVG) for diagrams

## Attribution

Third-party assets must include attribution and license information.
