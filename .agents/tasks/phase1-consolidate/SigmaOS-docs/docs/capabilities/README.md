# Capabilities & Feature Status

System capabilities, feature matrix, and current implementation status.

## Contents

- **capability-matrix.md**: Comprehensive matrix of system capabilities and their implementation status
- **feature-status.md**: Auto-generated feature status report (updated per release)

## Capability Categories

- **Resource Management**: Process, memory, and I/O management
- **Synchronization**: Concurrency primitives and locking mechanisms
- **Storage**: Filesystem and data persistence
- **Networking**: Network stack and protocol support
- **Scheduling**: Task scheduling and prioritization
- **Security**: Access control and authentication

## Feature Status

Feature statuses are tracked as:
- **Implemented**: Fully working in current release
- **In Development**: Active work in progress
- **Planned**: Scheduled for future release
- **Research**: Under investigation, not yet scheduled

See [feature-status.md](./feature-status.md) for detailed status.
