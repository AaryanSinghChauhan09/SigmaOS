# Developer Cookbook

Practical how-to guides and recipes for common SigmaOS development tasks.

## Guides

- **Development Setup**: Environment configuration and toolchain installation
- **Testing**: Writing and running tests, coverage analysis
- **Debugging**: Debugging techniques, logging, and troubleshooting
- **Releasing**: Release procedures, versioning, and distribution
- **Multi-Repo Workflow**: Working across SigmaOS and SigmaOS-docs repositories

## Quick Start

Each guide includes:
- Prerequisites and requirements
- Step-by-step instructions
- Common pitfalls and solutions
- Links to related documentation

## Contributing Recipes

To add a new recipe, open an issue describing the common task and submit a PR with documentation.
