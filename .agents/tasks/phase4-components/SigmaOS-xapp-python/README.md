# SigmaOS-xapp-python

Python bindings for the SigmaOS xapp library. Enables Python applications to use SigmaOS xapp widgets and APIs. Inspired by python3-xapp.

## Upstream

- [python3-xapp](https://github.com/linuxmint/python3-xapp)

## Build

```sh
pip install -e .
```
