# SigmaOS-theme-gtk3

GTK3 theme collection for SigmaOS. Provides polished GTK3 themes for all applications using the GTK toolkit. Inspired by mint-themes-gtk3.

## Upstream

- [mint-themes-gtk3](https://github.com/linuxmint/mint-themes)

## Build

```sh
make install
```

## Principles

- DRY: shared colour tokens reused across all GTK3 variants
- Modularity: light/dark/high-contrast variants are separate modules
- FOSS: MIT licensed
- KISS: single `make install` entry point
- Discoverability: COMPONENTS-entry.toml for registry lookup
