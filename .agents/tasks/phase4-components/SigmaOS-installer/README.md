# SigmaOS-installer

Graphical system installer application for SigmaOS, handling disk partitioning, user account creation, locale setup, and bootloader installation. Inspired by live-installer and ubiquity.

## Upstream Reference

- [live-installer](https://github.com/linuxmint/live-installer)
- [ubiquity](https://launchpad.net/ubiquity)

## Build Instructions

```bash
python3 src/main.py
```
