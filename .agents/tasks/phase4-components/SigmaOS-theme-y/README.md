# SigmaOS-theme-y

Y theme series for SigmaOS. The flagship SigmaOS visual theme series with light and dark variants. Inspired by mint-y-theme.

## Upstream

- [mint-y-theme](https://github.com/linuxmint/mint-y-theme)

## Build

```sh
make install
```

## Principles

- DRY: shared colour palette tokens power both light and dark variants
- Modularity: light, dark, and accent variants are independent packages
- FOSS: MIT licensed
- KISS: `make install` resolves all variant symlinks automatically
- Discoverability: COMPONENTS-entry.toml for registry lookup
