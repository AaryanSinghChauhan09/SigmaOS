# SigmaOS-quickshell

Quick launcher and shell for SigmaOS, providing a keyboard-driven application launcher, command runner, and shell with fuzzy search and plugin extensibility. Inspired by quickshell.

## Upstream Reference

- [quickshell](https://github.com/quickshell/quickshell)

## Build Instructions

```bash
# Ensure Python 3 is installed
python3 --version

# Launch quickshell
python3 src/main.py
```
