# SigmaOS-menus

Desktop application menus system for SigmaOS, implementing the freedesktop.org menu specification with dynamic menu generation and category management. Inspired by cinnamon-menus and mintmenu.

## Upstream Reference

- [cinnamon-menus](https://github.com/linuxmint/cinnamon-menus)
- [mintmenu](https://github.com/linuxmint/mintmenu)

## Build Instructions

```bash
# Build with Cargo
cargo build --release

# Run
cargo run
```
