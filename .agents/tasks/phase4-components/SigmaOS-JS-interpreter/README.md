# SigmaOS-JS-interpreter

JavaScript runtime interpreter for SigmaOS, providing a sandboxed ECMAScript environment for desktop extensions and scripting. Inspired by cjs and mozjs.

## Upstream Reference

- [cjs](https://github.com/linuxmint/cjs)
- [mozjs](https://hg.mozilla.org/mozilla-central/file/tip/js)

## Build Instructions

```bash
cargo build --release
```
