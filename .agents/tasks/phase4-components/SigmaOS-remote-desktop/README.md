# SigmaOS-remote-desktop

Remote desktop client and server for SigmaOS, supporting VNC and RDP protocols for accessing and sharing desktops across the network. Inspired by gliff.

## Upstream Reference

- [gliff](https://github.com/gliff-ai/gliff)

## Build Instructions

```bash
# Ensure Python 3 is installed
python3 --version

# Launch remote desktop
python3 src/main.py
```
