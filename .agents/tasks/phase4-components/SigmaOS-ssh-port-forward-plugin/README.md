# SigmaOS-ssh-port-forward-plugin

SSH port forwarding panel plugin for SigmaOS, providing a system tray interface to manage SSH tunnels, port forwards, and remote connections with one-click activation.

N/A — original SigmaOS component.

## Build Instructions

```bash
# Ensure Python 3 is installed
python3 --version

# Run the plugin
python3 src/main.py
```
