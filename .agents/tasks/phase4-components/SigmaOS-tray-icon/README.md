# SigmaOS-tray-icon

System tray icon library for SigmaOS. Provides a shared library for applications to display system tray icons and menus. Inspired by rhythmbox-tray-icon and libappindicator.

## Upstream

- [rhythmbox-tray-icon](https://gitlab.gnome.org/GNOME/rhythmbox)
- [libappindicator](https://launchpad.net/libappindicator)

## Build

```bash
cargo build --release
```
