# SigmaOS-simple-scan

A document scanner application for SigmaOS, providing simple and intuitive scanning of physical documents via flatbed or sheet-fed scanners. Supports PDF and image output formats with basic image correction. Inspired by GNOME Simple Scan.

## Upstream References
- [simple-scan](https://gitlab.gnome.org/GNOME/simple-scan)

## Build
```sh
cargo build --release
```
