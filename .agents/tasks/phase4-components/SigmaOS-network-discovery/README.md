# SigmaOS-network-discovery

Network device discovery tool for SigmaOS, scanning local networks to identify devices, services, and open ports using mDNS and UPnP protocols. Inspired by network-discovery.

## Upstream Reference

- [network-discovery](https://github.com/topics/network-discovery)

## Build Instructions

```bash
# Install dependencies
pip3 install -r requirements.txt

# Run
python3 src/main.py
```
