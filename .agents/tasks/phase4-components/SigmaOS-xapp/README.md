# SigmaOS-xapp

Cross-desktop application library for SigmaOS. Provides shared widgets, utilities, and APIs for building SigmaOS applications that work across desktop environments. Inspired by xapp.

## Upstream

- [xapp](https://github.com/linuxmint/xapp)

## Build

```sh
cargo build --release
```
