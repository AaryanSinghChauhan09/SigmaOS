# SigmaOS-theme-desktop-environment

Desktop environment themes for SigmaOS. Provides complete desktop environment visual themes including window borders, panel styles, and workspace decorations. Inspired by cinnamon-themes.

## Upstream

- [cinnamon-themes](https://github.com/linuxmint/cinnamon-themes)

## Build

```sh
make install
```

## Principles

- DRY: shared theme variables centralised in one place
- Modularity: each DE component themed independently
- FOSS: MIT licensed
- KISS: minimal, well-documented install steps
- Discoverability: COMPONENTS-entry.toml for registry lookup
