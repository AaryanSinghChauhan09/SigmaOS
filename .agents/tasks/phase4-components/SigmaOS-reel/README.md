# SigmaOS-reel

Screen recording and reel creation tool for SigmaOS, enabling capture of desktop sessions, editing of recordings into shareable reels, and export to common video formats. Inspired by omareel.

## Upstream Reference

- [omareel](https://github.com/omareel)

## Build Instructions

```bash
# Ensure Python 3 is installed
python3 --version

# Launch reel
python3 src/main.py
```
