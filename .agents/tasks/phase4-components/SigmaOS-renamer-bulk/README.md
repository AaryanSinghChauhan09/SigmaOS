# SigmaOS-renamer-bulk

Bulk file renaming tool for SigmaOS, supporting regex patterns, sequential numbering, metadata-based renaming, and preview before applying changes. Inspired by bulky.

## Upstream Reference

- [bulky](https://github.com/linuxmint/bulky)

## Build Instructions

```bash
# Ensure Python 3 is installed
python3 --version

# Launch bulk renamer
python3 src/main.py
```
