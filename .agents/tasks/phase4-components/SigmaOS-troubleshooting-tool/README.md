# SigmaOS-troubleshooting-tool

System diagnostic and troubleshooting tool for SigmaOS. Collect system reports, diagnose common issues, and guide users through fixes. Inspired by mintreport.

## Upstream

- [mintreport](https://github.com/linuxmint/mintreport)

## Build

```bash
cargo build --release
```
