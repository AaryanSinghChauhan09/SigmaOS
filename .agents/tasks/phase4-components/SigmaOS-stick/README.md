# SigmaOS-stick

A bootable USB drive creator for SigmaOS. Flash ISO images to USB drives safely and reliably. Inspired by Balena Etcher and MintStick.

## Upstream References
- [etcher](https://github.com/balena-io/etcher)
- [mintstick](https://github.com/linuxmint/mintstick)

## Build
```sh
cargo build --release
```
