# SigmaOS-sign

Digital document signing tool for SigmaOS, enabling users to create, apply, and verify digital signatures on documents using GPG and X.509 certificate infrastructure. Inspired by signed.

## Upstream Reference

- [signed](https://github.com/nicktindall/signed)

## Build Instructions

```bash
# Ensure Python 3 is installed
python3 --version

# Launch sign
python3 src/main.py
```
