# SigmaOS-plymouth

Boot splash screen for SigmaOS, providing animated startup graphics, theme management, and seamless transition from boot to login. Inspired by linuxmint/plymouth.

## Upstream Reference

- [linuxmint/plymouth](https://github.com/linuxmint/plymouth)

## Build Instructions

```bash
# Ensure plymouth is installed on your system
sudo apt install plymouth

# Run the theme installer
bash src/main.sh
```
