# SigmaOS-renamer-file

Single file renaming utility for SigmaOS, providing a focused interface for renaming individual files with name suggestions, conflict detection, and undo support. Inspired by pyRenamer.

## Upstream Reference

- [pyRenamer](https://github.com/SteveRyherd/pyRenamer)

## Build Instructions

```bash
# Ensure Python 3 is installed
python3 --version

# Launch file renamer
python3 src/main.py
```
