# SigmaOS-window-management-library

Window management shared library for SigmaOS. Provides core window management APIs, compositing support, and workspace handling. Inspired by muffin (Cinnamon's window manager).

## Upstream

- [muffin](https://github.com/linuxmint/muffin)
- [Mutter](https://gitlab.gnome.org/GNOME/mutter)

## Build

```sh
cargo build --release
```
