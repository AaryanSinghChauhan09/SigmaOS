# SigmaOS-draw

Vector and raster drawing application with layers, shape tools, and export to standard image formats. Inspired by the Maoschanz Drawing application architecture.

**Upstream inspiration:** https://github.com/maoschanz/drawing

**Dependencies:** `gtk4`, `cairo`, `SigmaOS-common`

**Build/Install:**
```
cargo build --release
sudo cp target/release/sigma-draw /usr/bin/sigma-draw
```
