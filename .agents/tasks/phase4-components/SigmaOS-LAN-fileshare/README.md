# SigmaOS-LAN-fileshare

Local network file sharing for SigmaOS, enabling fast peer-to-peer file transfer between devices on the same network with a simple drag-and-drop interface. Inspired by warpinator.

## Upstream Reference

- [warpinator](https://github.com/linuxmint/warpinator)

## Build Instructions

```bash
# Install dependencies
pip3 install -r requirements.txt

# Run
python3 src/main.py
```
