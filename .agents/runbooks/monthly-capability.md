# Monthly Capability Runbook

## Monthly Execution Flow

1. **Week 1: Theme Planning & Boot Contract**
   - Review monthly theme target from PR roadmap.
   - Define end-to-end boot/runtime path contract.

2. **Weeks 2–3: Integration & Testing**
   - Connect weekly mechanism slices into a user-visible vertical capability.
   - Run QEMU smoke and regression suites.

3. **Week 4: Capability Gate & Release Report**
   - Generate build manifest and test report artifacts.
   - Update `CAPABILITY_MATRIX.toml` with runtime evidence links.
   - Publish monthly capability report under `research/reports/monthly/`.
