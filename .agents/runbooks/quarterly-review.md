# Quarterly Review Runbook

## Quarterly Execution Flow

1. **Review Inputs Gathering**
   - Audit `CAPABILITY_MATRIX.toml` and `FEATURE_STATUS.toml`.
   - Collect QEMU boot logs, test pass rates, and security review items.

2. **Strategic Reset & Consolidation**
   - Archive research documents older than 2 quarters.
   - Update P0/P1/P2 gap register and quarterly themes.

3. **Output Publishing**
   - Publish quarterly report under `research/reports/quarterly/`.
   - Update `FUTURE-DEVELOPMENT-ROADMAP.md` and `docs/RELEASE_CRITERIA.md`.
