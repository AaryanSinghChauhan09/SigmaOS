# Runbook: Quarterly Architecture & Roadmap Review

## Purpose
Reassess system architecture, gap closures, security boundaries, and capability claims across all 12 core components every quarter.

## Tasks
1. Audit `CAPABILITY_MATRIX.toml` and `FEATURE_STATUS.toml` against runtime test logs.
2. Downgrade any capability claim lacking runtime evidence.
3. Archive stale research older than 2 quarters.
4. Reprioritize P0, P1, P2 backlog items.
5. Publish quarterly report in `research/reports/quarterly/`.
