# Quarterly Review Runbook — SigmaOS

## Objective
Reassess system architecture, gap analysis, security boundaries, roadmap progress, and archive stale plans.

## Workflow
1. Audit capability matrix against actual runtime evidence.
2. Archive research older than two quarters.
3. Review security threat model and capability constraints.
4. Update roadmap and reprioritize P0, P1, P2 backlog.
5. Save quarterly report to `research/reports/quarterly/`.
