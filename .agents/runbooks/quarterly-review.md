# Quarterly Review Runbook

## Objective
Reassess architecture, gaps, security posture, and roadmap; archive stale research; update P0-P2 backlog.

## Steps
1. Re-evaluate capabilityClaims in `CAPABILITY_MATRIX.toml` against runtime logs.
2. Archive research notes older than two quarters in `research/reports/quarterly/archived/`.
3. Update security threat models and fuzzing parser coverage.
4. Reprioritize P0-P2 improvement backlog items.
5. Publish quarterly roadmap report in `research/reports/quarterly/`.
