# Monthly Milestone Runbook

## Objective
Complete one component milestone and validate capability transition with runtime evidence.

## Cadence
Monthly cycle.

## Procedure
1. Verify monthly milestone goal in `CAPABILITY_MATRIX.toml` and `FEATURE_STATUS.toml`.
2. Gather runtime evidence (QEMU boot trace, serial log, installer test, or device log).
3. Enforce Rule 3: Promote component maturity level only when runtime evidence exists.
4. Record milestone completion in `research/reports/monthly/`.
