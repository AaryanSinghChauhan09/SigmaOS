# Monthly Component Milestone Runbook

## Objective
Progress one component domain to a new, verifiable milestone under the monthly component roadmap.

## Steps
1. Review monthly milestone target for current month (M1-M12).
2. Verify validation gate requirements (e.g. QEMU serial log, process-switch trace, or install/rollback tests).
3. Execute milestone validation script and capture proof artifact.
4. Record milestone status report in `research/reports/monthly/`.
