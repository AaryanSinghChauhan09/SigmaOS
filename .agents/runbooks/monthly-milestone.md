# Runbook: Monthly Component Milestone

## Purpose
Advance one core component to a new verifiable milestone according to the 12-month roadmap.

## Validation Gates
1. Verify component maturity requirements (`Proposed` -> `Prototype` -> `Integrated` -> `Hardened` -> `Supported`).
2. Run component-specific validation suite (e.g. QEMU boot, package corpus, installer rollback).
3. Publish monthly report in `research/reports/monthly/`.
