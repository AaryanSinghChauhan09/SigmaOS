# SigmaOS Sub-Repositories & Component Ecosystem

SigmaOS adopts a distributed multi-repository architecture modeled directly after enterprise distributions such as **Linux Mint** and **Omarchy Linux**. Each subsystem and standalone userland tool has a specialized repository, linked to the central `SigmaOS` microkernel umbrella.

### Architectural Principles Implemented
- **Component Isolation & Modular Kernel Design:** Clear boundaries between microkernel core and userland daemons.
- **Multiple Repositories Pattern:** Autonomous versioning, independent CI pipelines, and granular issue tracking.
- **Single Source of Truth:** Centralized documentation in `SigmaOS.wiki` while binary components evolve modularly.
