# Weekly Component Improvement Runbook

## Purpose
Study one upstream mechanism and improve exactly one SigmaOS component.

## Workflow
1. **Day 1**: Select one narrow target component and gap.
2. **Day 2**: Study upstream implementation in Linux, xv6, FreeBSD, OpenBSD, Arch, Debian, Fedora, or Redox.
3. **Day 3**: Write an Architecture Decision Record (ADR) in `research/decisions/`.
4. **Day 4-5**: Implement the smallest safe change.
5. **Day 6**: Validate using unit tests, integration tests, and runtime evidence (QEMU/hardware).
6. **Day 7**: Publish weekly improvement report in `research/reports/weekly/` and update capability status.
