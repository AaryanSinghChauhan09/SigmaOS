# Linux Distro Inspirations

- Arch Linux (AUR, pacman, rolling release, LVM, BTRFS)
- Ubuntu/Debian (apt compatibility, snap-like packages, accessibility)
- Fedora/RHEL (SELinux, systemd patterns, rpm concepts)
- NixOS (declarative config, reproducible builds)
- Gentoo (portage-style compilation, USE flags concept)
- Alpine Linux (musl libc patterns, minimal footprint)
- Kali Linux (security tools integration, penetration testing)
- Pop!_OS (Pop Shell tiling WM inspiration, cosmic DE)
- Clear Linux (Intel optimizations, bundle-based updates)
- Void Linux (XBPS-like package manager, runit-style init)
- Artix Linux (OpenRC/runit without systemd)
- AntiX (live system features, sysv init)
- Zorin OS (user-friendly layout switching)
- MX Linux (persistence in live mode, antiX base)
