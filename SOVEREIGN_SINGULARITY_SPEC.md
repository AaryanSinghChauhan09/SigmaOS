## 🚀 The Sovereign Singularity Commands

### Native Ascendance (Self-Hosting)
```bash
./s-cli ascend
```
Triggers the native self-compilation sequence. SigmaOS utilizes its own **Sovereign ASM (S44)** toolchain to compile its core and shards, subsequently migrating its execution directly to the target silicon gates. The OS is now 100% independent of the host build environment.

### Neural Sentinel (S62)
```bash
./s-cli sentinel
```
Engages the **Sovereign Sentinel**, an autonomous neural firewall that performs real-time anomaly detection across the lattice. It identifies and neutralizes malicious IPC traffic and network packets with zero human intervention.

### State Teleportation
```bash
./s-cli teleport [target_node]
```
Performs a zero-copy migration of the entire system state to a remote mesh node. This allows for seamless "teleportation" of your workspace across the global mesh, ensuring that your Sovereign Singularity is always where you need it to be.
