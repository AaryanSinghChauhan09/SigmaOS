# Zenith Desktop UX

SigmaOS features a bespoke graphical environment designed from the ground up: **Zenith Desktop**.

## Spatial Design Paradigm
Instead of a traditional Windows-style taskbar, Zenith adopts a clean, spatial UI:
- **Top Panel**: Global status bar providing system telemetry, network state, and global menus.
- **Spatial Dock**: A floating, frosted-glass launcher at the bottom of the screen containing pinned applications and active tasks.

## Theming Engine
Zenith has a built-in theme engine prioritizing aesthetics and eye comfort:
- Dark Mode (Default, tailored HSL colors)
- Light Mode
- High Contrast (For accessibility)

All UI elements are composited natively through `sigma-wm` via double-buffering.
