# Data Science Algorithms: Analytics Suite

Perform high-performance scientific computations, statistical modeling, and data analytics on-device without cloud dependency.

---

## 📈 Embedded Algorithms
- **Matrix Decompositions**: Singular Value Decomposition (SVD), LU decomposition.
- **Statistical Fitting**: Welch's T-test, ANOVA.
- **Time-Series Models**: ARIMA, LSTM workload prediction.

## 💾 Version Control
The integration with `dvc`-like versioning allows tagging the datasets and training weights with SovereignFS snapshots for full experiment reproducibility.
