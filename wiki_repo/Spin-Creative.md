# SigmaOS Creative Spin — Designer & Creator Edition

The **SigmaOS Creative** spin bundles a complete open-source creative suite for designers, artists, musicians, and video editors. Inspired by the creative-ready configurations of Ubuntu Studio and Fedora Design Suite.

---

## 🎨 Graphics & Visual Arts

| Tool | Purpose |
|------|---------|
| GIMP | Professional raster image editing |
| Krita | Digital painting & illustration |
| Inkscape | Vector graphics (SVG-first) |
| Blender | 3D modeling, animation & rendering |
| RawTherapee | RAW photo processing |
| Darktable | Photography workflow |

## 🎵 Audio Production

- **Ardour** — professional DAW with JACK/PipeWire support
- **Audacity** — quick audio editing & recording
- **LMMS** — music composition
- **Carla** — plugin host (VST/LV2/LADSPA)
- **PipeWire** — sovereign low-latency audio server (replacing PulseAudio)
- **JACK** — pro-audio routing daemon

## 🎬 Video Production

- **Kdenlive** — NLE video editor
- **OBS Studio** — live streaming & recording
- **Handbrake** — video transcoding
- **FFmpeg** — sovereign command-line media processing

## 🖋 Fonts & Typography

- **Sovereign Font Manager** — browse, install, and preview fonts
- Open Font Library integration (Google Fonts mirror, SIL)
- fontconfig tuning for sub-pixel rendering

## 🎛 Color Management

- **ICC profile** support built into compositor
- **DisplayCAL** — monitor calibration
- **colord** daemon — system-wide color consistency

## 🎙 Streaming & Broadcasting

- OBS Studio with sovereign plugin API
- VirtualCam (V4L2 loopback) for virtual webcam output
- NDI tools for network video distribution

---

## 🚀 Installation

```bash
sigma-spin install creative
```
