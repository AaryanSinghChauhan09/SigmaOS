# Post-Quantum Cryptography (PQC)

SigmaOS is future-proofed against the impending threat of cryptographically-relevant quantum computers (CRQCs) via its built-in PQC Shard.

## Dilithium-5
We have implemented stubs for the NIST-standardized **Dilithium-5** lattice-based signature scheme. This algorithm offers Level 5 security (equivalent to AES-256 brute force) against quantum attacks.

## Integration
The PQC shard is heavily integrated into the ecosystem:
- **OmniPackage Manager**: All `.omni` packages must be signed with Dilithium-5 keys. The package manager refuses to install binaries without verifying this signature.
- **Compliance Engine**: Audit reports generated by the OS are cryptographically signed using Dilithium-5, preventing malicious tampering.
