# 📟 SigmaOS: Sovereign Orchestrator v4.6 (Distro Synthesis)

The **Sovereign Orchestrator v4.6** synthesizes the best design principles from the global operating system ecosystem into a unified, high-performance lattice.

## 🚀 Distro Synthesis Commands

### Sovereign Containerization (S73)
```bash
./s-cli container [image_id]
```
Utilizes the **Sovereign Container** shard to spawn bare-metal, zero-overhead process isolation environments. It leverages native lattice namespaces and resource-clamping to provide industrial-grade security without the performance penalty of traditional container engines like Docker.

### Intelligent Hybrid Mode
```bash
./s-cli hybrid
```
Toggles an intelligent hybrid-kernel profile. It selectively maps critical system drivers into the kernel address space to minimize context-switching overhead, inspired by the architectures of **macOS** and **Windows NT**.

### Static Void Execution
```bash
./s-cli void
```
Enforces strict, musl-libc style static linking for all executing micro-shards. This eliminates runtime dependencies on shared libraries, ensuring absolute portability and stability, a core tenet of **Void Linux**.
