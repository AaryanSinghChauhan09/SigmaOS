## 🚀 Quick Start

**Open SigmaOS in 3 seconds:**
1. Open Chrome/Edge
2. Press `Ctrl+O`
3. Navigate to `SigmaOS/index.html`

Or double-click `BOOT_SIGMA_OS.bat` (Windows).

## 🏗️ Architecture

```
Browser (Chrome/Edge)
  └── Web Kernel v6.0 (index.html)
        ├── Window Manager (drag/resize/snap)
        ├── App Drawer (⊞ all apps)
        ├── Taskbar (running apps)
        ├── Omni-Search (Ctrl+Space)
        └── Notification Centre
  └── Silicon Layer (C++ / Rust / Assembly)
        ├── SigmaBootloader.asm
        ├── SigmaRustCore.rs
        └── SigmaLibC.c
```
