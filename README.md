## 🚀 GETTING STARTED

### Prerequisites
- `gcc`, `g++`, `nasm`, `make`, `bash`.
- `qemu-system-x86_64` (for Local Distro Runner).

### Build the Shard
```bash
make zenith
```

### Run Locally (Universal Distro)
```powershell
.\scripts\SigmaDistroRunner.ps1 -DistroPath path/to/any-distro.iso
```
