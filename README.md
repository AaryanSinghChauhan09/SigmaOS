## 🛠️ Getting Started

- `gcc` / `clang` (C++11/14 required for kernel shards)
- `nasm` (for boot-sector assembly)
- `qemu-system-x86` (for emulation and testing)

### Build the Lattice
```bash
make all            # Build the 600-shard core
./qemu-boot.sh      # Launch the Sovereign Lattice
```
