SigmaOS is an industrial-grade, sentient operating system architecture built on pure silicon primitives. It has been hardened into a zero-dependency Sovereign Lattice, eliminating high-level language runtimes in favor of native performance and security.

## 🏛 Native Architecture
- **Core Orchestrator:** Written in pure Rust with zero external dependencies.
- **Sovereign Shards:** Hybrid Rust/C shards for virtualization, security, and WASM isolation.
- **Unified CLI (`sigmactl`):** A native Rust binary for all system orchestration, setup, and maintenance.
- **Zenith Dashboard:** A zero-dependency web interface served directly by the Rust backend.

## 🚀 Getting Started
1. Set your root: `export SIGMA_ROOT=/path/to/SigmaOS`
2. Run the wizard: `./target/release/sigmactl wizard`
3. Build the lattice: `sigmactl build`
4. Start the dashboard: `./target/release/sigma-backend`

## 🏛️ The 33 Sovereign Suites
SigmaOS is built on a modular lattice of 33 suites, ranging from **Genesis (S01)** to **Terminal Fulfillment (S33)**. Every shard is 100% self-contained with **Zero HLL dependencies**.

## 🚀 Key Features
- **Apex Virtualization**: Native WASM JIT Engine and POSIX (Crostini) translation layer.
- **Zenith Dashboard**: Premium glassmorphic UI with multi-window support and real-time telemetry.
- **Universal Sync**: Distributed cross-browser state synchronization.
- **Security**: Zero-Trust shard namespacing and granular hardware permissions.

## 🛠️ Build & Development
### Requirements
- GCC 13+ (x86_64-elf cross-compiler recommended)
- NASM
- Python 3.10+ (for tooling)

### Quick Start
```bash
# Build the sovereign kernel
make bin

# Create bootable ISO
make iso

# Launch the system diagnostics
make diagnostics
```
