SigmaOS API v0.1

SigmaOS exposes OS capabilities to web apps via navigator.sigmaos. All APIs are promise-based and require user permission per site + capability.

Unix Philosophy: "If you can do it in bash, you can do it in a web app." SigmaOS ships low-level primitives (shell, wasm, device) instead of 100 high-level APIs. Apps compose ffmpeg | wasm-filter | save themselves.

Installation

Apps must include a sigmaos key in their web manifest to request permissions:

{
  "name": "SigmaNotes",
  "start_url": "/",
  "display": "standalone",
  "sigmaos": {
    "version": "0.1.0",
    "permissions": ["fs.read", "fs.write", "shell.exec"],
    "category": "productivity"
  }
}

navigator.sigmaos.version

string — Current API version. Example: "0.1.0"

navigator.sigmaos.fs

MethodPermissionDescription
readFile(path)fs.readRead file inside ~/SigmaOS. Returns Promise<Uint8Array>
writeFile(path, data)fs.writeWrite Uint8Array to path. Creates dirs. Returns Promise<void>
await navigator.sigmaos.fs.writeFile("notes/hello.txt",
  new TextEncoder().encode("Hello SigmaOS"));
const data = await navigator.sigmaos.fs.readFile("notes/hello.txt");

navigator.sigmaos.shell — The Escape Hatch

Run any installed binary in a bubblewrap sandbox with capability-scoped access. This single primitive replaces screenshot, zip, pdf, ocr, and 100 other APIs.

MethodPermissionDescription
exec({cmd, args, stdin?, env?, caps})shell.execRun a binary. Returns {ok, stdout: Uint8Array, stderr: Uint8Array, code}
pipe(...commands)shell.execChain cmd1 | cmd2 | cmd3. Each command's stdout feeds the next's stdin
// Screenshot without a screenshot API
await navigator.sigmaos.shell.exec({
  cmd: "/usr/bin/grim", args: ["-"],
  caps: ["bin:/usr/bin/grim", "wayland"]
});

// Pipe: tar | gzip
await navigator.sigmaos.shell.pipe(
  { cmd: "tar", args: ["cf", "-", "."], caps: ["bin:/usr/bin/tar", "fs:/tmp"] },
  { cmd: "gzip", caps: ["bin:/usr/bin/gzip"] }
);

navigator.sigmaos.pkg

Install Alpine packages at runtime. Binary lands in ~/.sigmaos/bin.

MethodPermissionDescription
ensure(packages)pkg.installInstall packages if missing. Returns list of newly installed
list()pkg.listList installed packages
await navigator.sigmaos.pkg.ensure(["ffmpeg", "tesseract"]);
// Now shell.exec can use them

navigator.sigmaos.script

Install background scripts (cron + systemd for web apps).

MethodPermissionDescription
install({name, content, on, caps})script.installInstall a .sh script. on = "boot" | "workspace-active"
logs(name)script.logsGet script output log
await navigator.sigmaos.script.install({
  name: "git-backup",
  content: "#!/bin/sh\ncd ~/.sigmaos && git add -A && git commit -m autosave && git push",
  on: "workspace-active",
  caps: ["bin:/usr/bin/git", "fs:~/.sigmaos", "net"]
});

navigator.sigmaos.wasm — WASI Sandbox

Run .wasm binaries under wasmtime with WASI capabilities. Apps ship C/Rust compiled to WASM.

MethodPermissionDescription
run({wasm, args?, caps?})wasm.runExecute WASI binary. Caps: fs:/path, env:K=V
const wasmBytes = await fetch("/my-filter.wasm").then(r => r.arrayBuffer());
const result = await navigator.sigmaos.wasm.run({
  wasm: new Uint8Array(wasmBytes),
  args: ["--input", "/tmp/photo.png"],
  caps: ["fs:/tmp"]
});

navigator.sigmaos.syscall — Filtered Exec

Run user-supplied binaries under seccomp-bpf + bubblewrap with explicit syscall and path restrictions.

MethodPermissionDescription
exec(binary, {syscalls, paths, args})syscall.rawRun binary with filtered syscalls. High trust.
// App needs ioctl for custom USB device
const bin = await fetch("/my-driver").then(r => r.arrayBuffer());
await navigator.sigmaos.syscall.exec(new Uint8Array(bin), {
  syscalls: ["openat", "read", "write", "ioctl"],
  paths: ["/dev/ttyACM0"],
  args: ["--baud", "115200"]
});

navigator.sigmaos.serial

Talk to serial devices (Arduino, 3D printers, serial consoles).

MethodPermissionDescription
getPorts()serial.accessList serial ports. Returns ["/dev/ttyACM0", ...]
open(port, {baud})serial.accessOpen serial port at given baud rate
write(port, uint8)serial.accessWrite bytes to open port
read(port)serial.accessRead bytes from port. Returns Promise<Uint8Array>
close(port)serial.accessClose serial port
const ports = await navigator.sigmaos.serial.getPorts();
await navigator.sigmaos.serial.open("/dev/ttyACM0", { baud: 9600 });
await navigator.sigmaos.serial.write("/dev/ttyACM0",
  new TextEncoder().encode("LED_ON\n"));

navigator.sigmaos.bluetooth

Connect BLE devices via BlueZ D-Bus.

MethodPermissionDescription

const gamepad = await navigator.sigmaos.bluetooth.requestDevice({

navigator.sigmaos.theme — Magic Theme

OS-wide theme control. Magic mode auto-matches page background colors.

MethodPermissionDescription
get()noneGet current OS theme ("light" | "dark")
set(theme)noneSet OS theme + data-sigmaos-theme attribute
matchPage()noneAuto-detect page brightness and set theme
await navigator.sigmaos.theme.set("dark");
await navigator.sigmaos.theme.matchPage(); // auto-detect from page CSS

navigator.sigmaos.device — Generic /dev Access

Open any device file with capability checks. Replaces dedicated USB/serial/bluetooth APIs for advanced use.

MethodPermissionDescription
open(path)device.raw:/dev/...Open device. Returns fd (integer)
read(fd)—Read from device. Returns Uint8Array
write(fd, data)—Write to device
ioctl(fd, req, data)—Send ioctl to device
close(fd)—Close device
// Talk to a 2027 laser cutter — no OS update needed
const fd = await navigator.sigmaos.device.open("/dev/laser0");
await navigator.sigmaos.device.write(fd, new TextEncoder().encode("G28\n"));
await navigator.sigmaos.device.close(fd);

navigator.sigmaos.mem — Shared Memory

Create POSIX shared memory segments for zero-copy IPC with WASM modules.

MethodPermissionDescription
shm(name, size?)mem.shmCreate /dev/shm/sigmaos_<name>. Returns path
const shmPath = await navigator.sigmaos.mem.shm("video_buffer", 1024*1024*64);
// WASM module can mmap this path for zero-copy access

First call to any privileged API shows a prompt. User grants per origin + capability. Revoke in Settings > Apps.

Design: Unix Primitives Kill Dependency

Old WayNew Primitive WayWhy It Scales
navigator.sigmaos.screenshot()shell.exec({cmd:"grim"})100s of tools exist. Ship 0.
navigator.sigmaos.zip()shell.pipe(tar, gzip)Unix already solved this.
navigator.sigmaos.pdf()pkg.ensure(["libreoffice"])Reuse 30-year-old code.
navigator.sigmaos.ocr()pkg.ensure(["tesseract"])No ML model to maintain.
navigator.sigmaos.usb.ioctl()device.ioctl(fd, req)Any /dev, any ioctl.
