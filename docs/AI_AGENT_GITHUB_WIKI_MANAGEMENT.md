# AI Agent GitHub Wiki Management in SigmaOS

## Overview
SigmaOS features an automated, AI Agent-managed GitHub Wiki documentation system. Autonomous AI agents (**Sentinel** 🛡️, **Bolt** ⚡, **Palette** 🎨) synchronize, generate, validate, and maintain documentation consistency across the primary repository, in-repo wiki mirrors (`WIKI/`, `wiki/`, `wiki_repo/`), and the standalone GitHub Wiki repository (`https://github.com/AaryanSinghChauhan09/SigmaOS.wiki.git`).

AI agents interact directly with `src/sovereign_wiki_master_engine.rs` (`SovereignWikiMasterEngine`), `src/expanded_wiki_innovations.rs`, and automation scripts (`scripts/sync_wiki.sh`).

---

## 1. Multi-Directory Mirroring & Architecture

To maintain high availability and off-line documentation self-sufficiency, the GitHub Wiki is mirrored across three in-repo directories:
* **`WIKI/`**: Canonical Markdown documentation repository synced with GitHub Wiki root pages.
* **`wiki/`**: Extended technical blueprints, architecture specifications, and gap-closing roadmaps.
* **`wiki_repo/`**: Standalone Git workspace mirror for direct pushing to `SigmaOS.wiki.git`.

---

## 2. AI Agent Operational Protocols & Workflows

### 2.1 Automated Page Synchronization
When an AI agent modifies core system code, kernel primitives, packaging formats, or security rules:
1. **Delta Inspection**: Agent calculates the documentation delta between codebase implementations (`src/`) and existing wiki pages.
2. **Multi-Mirror Synchronization**: Agent updates `ImprovementPlan.md` and `NEXT_STEPS_GUIDELINES.md` in root and synchronizes copies across `WIKI/`, `wiki/`, and `wiki_repo/`.
3. **Automated Git Sync**: Agent triggers `scripts/sync_wiki.sh` or invokes `SovereignWikiMasterEngine::sync_all_repositories()` to push updates directly to `SigmaOS.wiki.git`.

### 2.2 Content Freshness & Link Validation Audits
AI agents run automated documentation audits during pre-commit cycles:
* **Broken Link Detection**: Scan relative Markdown links (`[Title](Page.md)`) for dead targets.
* **Orphaned Page Cleanup**: Detect pages unreferenced by `Home.md` or `_Sidebar.md`.
* **Code-Doc Drift Prevention**: Verify that listed API functions, package formats, and CLI flags match active Rust function declarations in `src/`.

---

## 3. Compliance & Formatting Rules for Wiki Management

1. **Standardized Header Structure**:
   All wiki pages must begin with a clear H1 title (`# Title`), Executive Summary, Architectural Blueprint, and Navigation Footer.
2. **Markdown Accessibility**:
   AI agents must ensure image URLs include descriptive `alt` text (`![Alt Text](url)`) and code blocks specify explicit syntax highlighting (````rust`, ````bash`, ````toml`).
3. **PQC Signature Integrity**:
   Critical release documentation and checksum manifests posted to the wiki must include Dilithium-5 post-quantum signature verification hashes generated by `Dilithium5KernelSignatureVerifier`.

## 4. Sample Agent Commands & CLI Interactions

```bash
# Perform full wiki synchronization across in-repo mirrors and GitHub Wiki
sigma-wiki sync --all

# Run documentation freshness and broken-link audit
sigma-wiki audit-links --dir WIKI/

# Rebuild GitHub Wiki sidebar and navigation tree
sigma-wiki generate-sidebar --root wiki_repo/
```
