# 🇸🇴 AI Agents Cache Management Architecture in SigmaOS

## Executive Overview

SigmaOS introduces an **autonomous AI Agent Cache Management Architecture** engineered to dynamically optimize multi-level CPU L1/L2/L3 caches, VFS page caches, kernel SLAB/Slab object caches, FreeBSD ZFS ARC/L2ARC pools, and zswap/zram compressed memory caching in real time. Operating directly inside SigmaOS's zero-dependency `#![no_std]` Rust microkernel and userland layer, AI Cache Governors continuously analyze memory access patterns, cache hit/miss ratios, and pressure stall telemetry to maximize system responsiveness while minimizing memory allocation overhead.

Drawing deep inspiration from Linux memory access frameworks (DAMON, PSI, zswap/zram, SLUB/SLAB) and BSD virtual memory systems (FreeBSD ZFS ARC, UVM page caching, NetBSD rump cache partitioning), SigmaOS AI Cache Agents deliver intelligent, zero-overhead memory and cache orchestration.

### 1. Linux Kernel Caching Paradigms Absorbed
- **DAMON (Data Access Monitor) & Page Cache Reclaim:** Cache agents analyze real-time page access heatmaps generated by DAMON, proactively reclaiming cold VFS page caches before memory pressure triggers OOM conditions.
- **Pressure Stall Information (PSI):** Real-time `PSI_SOME` and `PSI_FULL` memory/cache pressure metrics inform cache agents when to shrink dentry/inode caches or expand compressed memory pools.
- **zswap & zram Compressed Caching:** Memory cache agents dynamically adjust LZ4/ZSTD compression ratios and pool sizes for zswap write-through buffers and zram swap devices.
- **SLUB / SLAB Kernel Object Caching:** Object cache agents shrink or merge idle kernel SLAB caches (e.g., inode, dentry, socket, buffer_head objects) to free physical pages for active workloads.

### 2. BSD Virtual Memory Paradigms Absorbed
- **FreeBSD ZFS Adaptive Replacement Cache (ARC & L2ARC):** Caching agents continuously balance the ZFS ARC Most Recently Used (MRU) and Most Frequently Used (MFU) lists while dynamically sizing L2ARC SSD read caches based on NVMe IOPS availability.
- **NetBSD UVM & Rump Kernel Cache Partitioning:** Micro-domain drivers and container environments run with isolated page cache quotas, preventing runaway processes from thrashing the shared system cache.

## 🤖 Core AI Cache Governors

SigmaOS deploys five microkernel AI agents dedicated to cache management:

### 1. Page Cache & Reclaim Governor Agent (`PageCacheGovernorAgent`)
- **Real-Time Telemetry:** Tracks VFS page cache hit/miss ratios, dirty page generation velocity, and DAMON page access frequencies.
- **Autonomous Actions:**
  - Evicts cold page caches proactively during heavy background AI model training or code compilation.
  - Flushes dirty page buffers adaptively to smooth disk write spikes.

### 2. CPU L1/L2/L3 Cache Allocation Agent (`CpuCacheAllocatorAgent`)
- **Real-Time Telemetry:** Monitors hardware performance counters (PMU) for L1/L2/L3 cache miss rates, instruction-per-cycle (IPC) stalls, and NUMA interconnect traffic.
- **Autonomous Actions:**
  - Configures Intel CAT (Cache Allocation Technology) / AMD L3 QoS bitmasks to partition L3 cache ways for latency-sensitive Zenith Desktop threads vs. background tasks.
  - Migrates threads across CPU cores to minimize L3 cache thrashing and cross-socket NUMA cache line invalidations.

### 3. Kernel SLAB & Object Cache Agent (`SlabCacheGovernorAgent`)
- **Real-Time Telemetry:** Tracks object allocation/free velocity across kernel SLAB caches (`kmalloc-128`, `inode_cache`, `dentry_cache`).
- **Autonomous Actions:**
  - Triggers automated SLAB cache shrinking (`kmem_cache_shrink`) when kernel object utilization drops below target efficiency thresholds.
  - Pre-allocates slab objects before anticipated process fork bursts to ensure zero-latency kernel allocation paths.

### 4. ZFS ARC & L2ARC Adaptive Agent (`ZfsArcAdaptiveAgent`)
- **Real-Time Telemetry:** Reads ZFS ARC hit ratios (`arcstats`), MRU vs. MFU eviction list lengths, and L2ARC SSD write endurance metrics.
- **Autonomous Actions:**
  - Dynamically adjusts `vfs.zfs.arc_max` and `arc_min` bounds based on global physical memory pressure.
  - Routes high-frequency metadata queries directly into L2ARC NVMe devices to accelerate file search operations.

### 5. zswap / zram Compressed Memory Cache Agent (`CompressedCacheAgent`)
- **Real-Time Telemetry:** Monitors memory compression ratios, CPU cycle overhead spent on LZ4/ZSTD compression, and zswap pool saturation.
- **Autonomous Actions:**
  - Dynamically expands zswap pool capacity during RAM-intensive workloads, delaying hard disk swapping.
  - Switches compression algorithms (e.g., from LZ4 to ZSTD) when higher compression density is needed under extreme memory pressure.

## 📡 Protocol Integration (ACP / MCP)

### Agent Client Protocol (ACP)
- Standardized stdio/JSON-RPC protocol enabling userland tools (`sigma-sh`, `intelligent_terminal`, `Zenith Desktop`) to query cache statistics, flush specific cache tiers, or adjust ARC/zswap bounds.

### Model Context Protocol (MCP)
- Exposes real-time cache telemetry to local LLMs (`QwenPaw`, `KimiCodeAgent`) while enforcing OpenBSD `unveil` file boundaries and capability limits.
