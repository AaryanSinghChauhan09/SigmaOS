# Developer Tools Bundle

SigmaOS treats developers as first-class citizens by shipping a massive array of pre-configured compilers and tools, all safely compartmentalized in Ephemeral Dev Sandboxes.

## The Toolkit
- **Compilers:** GCC, Clang, Rust (cargo), Python, Node.js, Java.
- **Editors/IDEs:** VSCodium (telemetry-free VS Code alternative) and Neovim.
- **Version Control:** Git with a native Wayland GUI frontend.
- **Design & Algorithms:** PlantUML for diagramming, and built-in libraries (Boost, Eigen, NumPy, SciPy) mapped into developer sandboxes.
