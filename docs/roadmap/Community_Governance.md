# Community & Governance Roadmap

## Contributor Onboarding
SigmaOS maintains comprehensive migration guides and architecture walkthroughs to lower the learning curve for contributors transitioning from Linux.

## Roadmap Voting
Future feature matrices are dictated by transparent community voting via GitHub Discussions and Issues.

## Incubator Program
Experimental features (e.g., alternative UI toolkits, niche filesystems) enter the SigmaOS Incubator, ensuring they mature in isolation before being proposed for merging into the LTS core.
