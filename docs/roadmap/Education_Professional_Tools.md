# Education & Professional Tools Roadmap

## Vision
SigmaOS is designed to be an "OS + Ecosystem" out of the box, preventing users from needing external, potentially unsafe downloads.

## Bundled Applications
- **Education Suite:** GeoGebra, Scilab, Octave, Moodle (local instances).
- **Professional Modules:** ERPNext, Koha (Library Management), GNUCash, QGIS.

All bundled software is managed via the atomic `sigpkg` system and runs under the strict MicroVM Sandboxing layer for security.
