# SigmaOS Component Rules Directory

This directory contains component-specific mandatory rules, safety boundaries, prohibited practices, required evidence, and capability promotion criteria for each SigmaOS domain.

Every component rule must be testable and connected to code, tests, CI, documentation, and a runtime validation path.
