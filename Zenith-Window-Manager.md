# Zenith Window Manager (`sigma-wm`)

The Zenith Window Manager serves as the bridge between kernel graphics output and the Zenith Desktop UI. It handles the low-level compositing of multiple windows into a single unified framebuffer.

## Features
- **Double Buffering**: Prevents screen tearing by drawing to an off-screen buffer before swapping.
- **Z-Indexing**: Fully supports overlapping windows, tracking foreground/background order.
- **Kernel/User Boundary**: Designed to execute compositing logic safely without direct userland hardware access.

## Interaction with Device Manager
`sigma-wm` binds tightly to devices marked as `DEV_TYPE_GPU` to acquire the master framebuffer, routing UI draw calls generated by `SovereignSpatialUI` into physical screen pixels.
